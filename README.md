# Project Documentation Hub

This repository defines an encrypted, zero-knowledge Windows backup application with pluggable remote storage. Telegram is the first MVP storage backend, not a permanent architectural dependency.

## Source-of-truth order
1. `AGENTS.md` — rules for every LLM/developer.
2. `PRODUCT.md` — product intent and scope.
3. `SECURITY.md` / `CRYPTOGRAPHY.md` — mandatory security constraints.
4. `ARCHITECTURE.md` — technical boundaries.
5. `PLAN.md` — executable build state.
6. `DECISIONS.md` — human decisions and ADR-like records.
7. `RESEARCH_LOG.md` — append-only chronological work log.

Start every session by reading `AGENTS.md`.
