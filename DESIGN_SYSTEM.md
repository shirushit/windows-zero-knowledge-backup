# Design System

## Character
Modern Windows 2026 utility: restrained, precise, spacious, premium icons, subtle motion, strong hierarchy. Avoid excessive gradients, glowing AI motifs, chatbot styling, glass everywhere, or decorative animation that obscures status.

## Tokens
Define semantic tokens in code: background, surface, elevated surface, primary, success, warning, danger, text primary/secondary/muted, borders, focus, spacing scale, radii, typography, elevation, motion durations. Support light/dark without component-local raw colors.

## Components
App shell, navigation, status card, folder row/tree, backup timeline, file browser, search, progress, banners, dialogs, settings rows, empty/error/loading states, tray menu.

## Motion
Use motion to explain state transitions: backup activity, completion, expanding trees, restore progress. Respect reduced-motion accessibility setting.
